# Competency questions (mapping contract)
1. Which publications explicitly identify a verified 510(k)? Article → detection → link assertion → device.
2. Which of these devices have recalls? Device → recall (adapter vocabulary).
3. Which trials connect publications and devices? Article → NCT identifier → trial → device.
4. Which diseases/chemicals co-occur? Article → annotation → typed normalized entity.
5. How do MeSH topics vary over years/categories? Article → date/MeSH assignment; device → category.
6. Who funded these publications? Article → grant → agency/identifier.
7. Which publications identify PMAs? Detection scheme + verified assertion.
8. Which recalled categories have little literature? Category/device/recall with optional publication counts.
9. Which candidate links need review? Assertion status/method/evidence location.
10. Which articles lack identifiers or have conflicting matches? Explicit identifiers and assertions.
